# Food-Delivery-System
Java OOP Project showcasing a Food Delivery System with a Swing GUI for users.
• Developed an object-oriented food delivery application with role-based users (Admin, Customer, Driver) for restaurant browsing, order placement, and delivery tracking.
• Applied OOP principles (Abstraction, Encapsulation, Inheritance, Polymorphism) and a layered architecture, integrating a Java Swing interface with a SQL Server database via JDBC
